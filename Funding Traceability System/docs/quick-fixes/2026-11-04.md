## 1. 评分完整性与权重校验

- 新增评分时得分默认为空，不再把未填写当作0分。
- 所有当前指标必填；空值、漏项、未知/重复指标、超出0—100的分数会被后端拒绝，新增和编辑均在写库前校验。
- 当前权重必须在0—100范围且合计100%；指标可以分步调整，但配置不完整时不能保存评分。
- 真实0分合法；客户端提交的总分和权重不参与服务端计算。
- 未完整填写时页面显示“待完整填写”，不预览完整综合分。

第一轮边界：当时未提供“不适用”标记、部分指标评分或历史规则快照。第二轮已提供新评分规则快照；“不适用”和部分指标评分仍未实现。本次不会批量修改既有评分。

## 2. 敏感详情15分钟无操作失效

适用范围为“隐私审批→敏感详情”弹窗，不是整个浏览器或所有学生档案页面。

- 在弹窗内发生鼠标、触摸、滚动或键盘交互时刷新客户端空闲期限，并向服务端合并上报活动（最多每30秒一次）。没有操作时定时器只检查截止时刻，不发送续期请求。
- 服务端采用滑动空闲期限，默认15分钟；最长会话默认2小时，且展示不得超过当前申请的审批授权截止时间。
- 前端按本地最后一次交互、服务端空闲截止和授权/最长截止中的最早时刻关闭。活动上报会被节流，服务端期限以收到的活动为准；网络延迟或失败可能使页面提前关闭，不能靠自动轮询无限续期。
- 会话读取、续期绑定当前登录用户和申请单；关闭只允许本人，关闭或到期的会话不可续期复活。兼容保留的adminId参数不再作为认证依据。
- 关闭/超时立即清空该弹窗详情、停止计时、撤销会话；迟到的创建或详情响应不能重新填回已关闭视图。后台标签页恢复时重新检查真实经过的时间。
- 续期失败返回业务码410，避免把查看会话到期直接当作整站登录失效。真正未登录仍返回401。
- Redis仅作可选缓存，数据库是会话授权依据；Redis未部署或丢失缓存不覆盖数据库的授权和关闭状态。

可选配置（不填则使用默认值）：

```yaml
privacy:
  sensitive-session-expire: 15
  sensitive-session-max: 120
```

请使用正数，空闲时限与最长时限均以分钟计。原有`expire_time`保存滑动空闲截止，`start_time`约束绝对期限，`target_profile_id`实际绑定调阅申请ID。旧有效会话也受最长时限约束，升级后建议重新打开敏感详情。

## Windows本机MySQL回归

先把本次变更文件合并到本机项目。需要MySQL 8、可用的`mysql.exe`、Maven、JDK（推荐17或21）以及Node18及以上；MySQL账号须有创建/删除独立测试库权限。在含`backend`、`frontend`、`docs`的项目目录打开PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\quick-fixes\run-local-mysql.ps1
```

脚本仅允许连接本机MySQL，在本地弹窗输入数据库凭据，不需要在聊天中提供密码。每次创建唯一的`funding_quickfix_*`业务库和隐私库，在独立目录复制后端源码构建，用127.0.0.1:18090启动测试实例并执行上述21项专项检查；不会导入或覆盖原有库，也不会重打包原项目的`target`。端口已占用则停止，或用`-Port 18091`换端口。

如果`mysql.exe`不在PATH，例如：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\docs\quick-fixes\run-local-mysql.ps1 -MySqlExe "C:\Program Files\MySQL\MySQL Server 8.0\bin\mysql.exe"
```

Maven、Java、Node路径可分别通过`-MvnExe`、`-JavaExe`、`-NodeExe`指定，非3306端口用`-DbPort`。默认结束时停止本次后端并删除本次创建的测试库；需要保留独立测试数据时加`-KeepTestDatabases`。结果和本地日志保存在`docs/testing/evidence/quickfix-日期-随机码/`。该脚本只跑21项专项检查，不包含完整Postman集合或浏览器测试；不需要运行原始`init_test_db.sql`。

## 部署后建议手工核对

1. 新建评分：不填某项应看不到总分且无法提交，填0应能提交；配置权重不足100%应被拒绝。
2. 打开隐私审批敏感详情：在弹窗内操作后空闲倒计时更新；不操作达到空闲期限后关闭；查看后台网络确认空闲时没有自动续期。
3. 用另一个账号或另一个申请单配合同一会话key调用接口，应被拒绝；不要在公开日志中记录真实会话key或学生隐私。
4. 关闭弹窗或离开页面后，确认返回的慢请求不会重新展示隐私；审批期限已到时不能通过活动续期。
