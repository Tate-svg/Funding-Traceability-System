## 二、测试工具与执行命令

### 2.1 JUnit 单元测试（Mock，不连数据库）

```powershell
cd backend
mvn -B test
```

- 共 6 个测试类、**53 个测试方法**，全部通过（Failures 0 / Errors 0 / Skipped 0）。
- 全部使用 Mockito Mock 掉 Mapper / 权限组件，**不连接任何数据库，不会污染业务库**。
- 运行日志：`docs/testing/evidence/junit-test-run.log`；Surefire 报告：`backend/target/reports/surefire.html`（运行 `mvn surefire-report:report-only` 生成），交付副本见 `docs/testing/evidence/junit-report/surefire.html`。

### 2.2 Postman 接口测试（newman 批量执行）

```powershell
# newman 6.2.3 安装到 .tools/newman（不入库）
npm install --prefix .tools/newman newman@6.2.3 newman-reporter-htmlextra

  docs/testing/postman/Funding-Traceability.postman_collection.json `

  -r cli,json,htmlextra `
  --reporter-json-export docs/testing/evidence/postman-result.json `
  --reporter-htmlextra-export docs/testing/evidence/postman-report.html
```

- 集合共 **80 个请求、201 条断言**，全部通过。
- 执行顺序：`00-前置登录` → `01-功能测试` → `02-权限测试` → `03-安全测试`。
- 只需运行某一类：追加 `--folder "02-权限测试"`。
- 运行日志：`docs/testing/evidence/postman.log`；结构化结果：`postman-result.json`；可视化报告：`postman-report.html`。

### 2.3 JMeter 性能测试（500 并发）

```powershell
# JMeter 5.6.3 解压在 .tools/apache-jmeter-5.6.3（不入库），且 java 需在 PATH 中
cd docs/testing/jmeter
..\..\..\.tools\apache-jmeter-5.6.3\bin\jmeter.bat -n `
  -t Funding-Traceability-Performance.jmx `
  -JTHREADS=500 -JLOOPS=5 -JRAMP_UP=2 `
  -l ../evidence/jmeter-result.jtl -e -o ../evidence/jmeter-report
```

- `setUp` 线程组自动登录并提取 JWT Token、溯源核验码，主线程组 500 线程复用。
- 压测场景：`POST /api/privacy/access/apply`（申请提交）+ `GET /api/public/verify`（溯源查询）。
- `-J` 参数可覆盖 `THREADS/LOOPS/RAMP_UP/PORT/BASE_URL/USERNAME/PASSWORD` 等变量，默认即 500 线程。
- 图形化汇总报告：`docs/testing/evidence/jmeter-report/index.html`；原始样本：`jmeter-result.jtl`。

## 八、缺陷与风险记录

| 编号 | 级别 | 描述 | 状态 |
| --- | --- | --- | --- |
| B-01 | 高 | 资助人仅初审通过（PENDING_L2）时，`/api/privacy/mask/getSensitiveDetail` 未校验具体申请单终审状态，持 `privacy:view:direct` 的审核管理员可提前看到明文 | 已修复并回归（P-28） |
| B-02 | 高 | 初审通过后资助人侧曾可查看明文（接口返回 masked=false） | 已修复并回归（F-11） |
| R-01 | 低 | 路径参数类型非法时，`GlobalExceptionHandler` 将异常 message 原样返回，包含 Java 类型名（如 `java.lang.Long`），属低危信息泄露；建议统一为“参数格式不正确” | 已记录，未修复 |
| R-02 | 提示 | `AUDIT_ADMIN` 的 `privacy:view:direct` 仍可在档案核验场景直接查看明文（设计允许，全程写 `privacy_access_log` 留痕）；如合规要求更严格，可改为必须持有效申请单 | 设计确认 |
| R-03 | 提示 | Demo 账号密码明文存储、密码明文比对（`AuthServiceImpl`），生产环境需改为 BCrypt + 参数化查询（当前查询已参数化） | 已知设计简化 |
| R-04 | 提示 | 登录失败与密码错误返回不同提示（“用户不存在/密码错误”），可用于账号枚举；建议统一提示 | 已知风险 |
| R-05 | 提示 | 测试环境 JWT 有效期 24h，未实现服务端吊销（logout 仅前端清 Token）；生产建议引入黑名单/短令牌 + 刷新令牌 | 已知风险 |
